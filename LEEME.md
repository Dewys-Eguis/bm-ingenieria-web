# BM Ingeniería y Energía — versión v10

Esta carpeta contiene la versión estática completa del sitio.

## Abrir localmente
Abra `index.html` en Chrome y, si venía de una versión anterior, use `Ctrl + F5`.

## Galería
La galería usa **6 fotografías locales** dentro de `assets/galeria/` en formato WebP optimizado para web. Las copias originales PNG entregadas para esta versión están en `assets/galeria/originales/`.

El carrusel incluye flechas, miniaturas, recorrido automático, pausa al pasar el mouse, navegación con teclado y gesto swipe en móvil. Las imágenes no abren un lightbox ni salen del carrusel.

## Movimiento y scroll
La versión v10 suaviza las entradas por scroll, reduce desplazamientos laterales bruscos y compacta el espacio entre las secciones de proceso y tecnología. También estabiliza el header al hacer scroll.
